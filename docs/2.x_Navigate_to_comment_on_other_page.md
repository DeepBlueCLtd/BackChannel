# Task: Support Cross-Page Comment Navigation in BackChannel

## Summary

When the BackChannel (BC) sidebar is open and configured to show comments across all pages in a feedback package, clicking a comment for another page should:

1. Navigate to the correct page.
2. Highlight and activate the target comment on that page.

## Implementation Plan

### 1. Use Fragment Identifier to Transfer Comment ID

Use an HTML fragment (`#bc-xxxx`) in the URL to encode the target comment ID.

- Example: Navigating to `page2.html#bc-1234` means the comment with ID `1234` should be highlighted and activated on `page2.html`.

### 2. On Sidebar Comment Click (in sidebar spanning all pages)

Update click handler logic:

```js
function handleCrossPageCommentClick(targetPage, commentId) {
  window.location.href = `${targetPage}#${commentId}`;
}
```

### 3. On Page Load, Detect Fragment and Activate Comment

On the new page, detect `window.location.hash` and highlight the target comment:

```js
document.addEventListener('DOMContentLoaded', () => {
  const hash = window.location.hash;
  if (hash.startsWith('#bc-')) {
    const commentId = hash.slice(4); // I _think_ this will retrieve the unique id
    openSidebarIfClosed(); // Custom function to ensure sidebar is visible
    // find the subject comment
    const el = document.getElementById(commentId);
    // ensure the comment is visible
    el.scrollIntoView({ behavior: 'smooth' });
    // click the comment, to make the browser scroll to the subject text, and apply highlighting
    el.click();
    }
  }
});
```

### 4. Ensure Comments Have Consistent IDs

Each comment should have a unique `id` in the format of a stringified timestamp.

### 5. Optional Enhancements

- Add a CSS class to flash or highlight the element.
- Ensure anchor `name="bc-xxxx"` is also supported for legacy compatibility.
- Allow sharing deep links to specific comments.

## Deliverables

- Updated sidebar click handler
- Page-load logic to parse fragment and activate corresponding comment
- Testing with multi-page feedback packages
- CSS highlight effect (optional)
